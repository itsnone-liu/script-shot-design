## 故事（创意机制：装睡揭示，攻防反转）
周日早晨。W 趴在 M 身上哄他起床去吃 brunch，M 装睡耍赖；W 升级攻势（戳脸→捏鼻子
→威胁自己走）；M 突然翻身把她压进被子——"再睡五分钟，你陪我"；反转后亲昵收尾，
揭示他从头装睡：从她说 brunch 那刻就在盘算怎么把她按回来。

升级链（三级）：戳脸（轻）→捏鼻（中，呼吸梗）→威胁要走（重）→被反制（揭示）。

## 身份逼近方案（女角：单张 45° 侧脸参考，2026-09-16 用户提供）

原图资产：798×1024 竖图，右 3/4 侧脸（右脸右眼清晰/左脸发遮），鹅蛋脸、深棕黑
中长直发、冷白皮、豆沙唇、杏仁眼、白衬衫（衣着不迁移，剧情换居家睡衣）。
核心思想：**一张图不当万能参考，先扩成一套资产包**；原图全程做门禁基准。

### 三层逼近（concert30 v3 配方移植 + 单图适配）
1. **L1 转正组**（新增第一步）：Ref2VA 以原图为唯一参考，生成同人**多角度标准照**：
   正面 / 左3/4 / 右3(原图角度同侧强化) / 仰视（C 段男上女下必需）/ 俯视 / 说话口型帧。
   **门禁自动化**：每张 vs 原图 SFace 嵌入余弦 ≥ 阈值（折扣 0.1-0.15，820 暗场教训），
   不过重生成；整组过用户一次验收，之后全自动。
2. **L2 场景生成**：关键帧用参考图配方——人脸裁切锚 P1（原图脸特写）+ SameFace 0.5 +
   硬属性卡（深棕黑中长直发/鹅蛋脸/冷白皮/豆沙唇，进所有提示词）+ 单一卧室场景 +
   转正组按镜头角度选锚（A 段选右3/4=原图同角度，C 段选仰视图）。
3. **L3 ReActor 逐帧修复**：生成后把脸换回原图几何（0.60-0.69 验证路线）。
   双人链式修复按体位切窗：A 段脸索引稳定→固定索引链修；B 段翻身运动帧脸模糊/遮挡
   →**跳修或轻修**（运动段宽容度高，硬修会抖）；C 段仰脸重遮窗修。

### 镜头设计迁就参考（最便宜的逼近手段）

- C 段仰脸不可避免，全靠 L1 仰视图锚 + L3 修复兜底
