# 接缝工程 V1 — AI 拼片硬切突兀的体系化解法

来源：用户指出 V4 硬切突兀并要求调研普遍性（2026-10-31）。外部佐证：invideo（Frankenstein editing / cut-hide / 静帧切失败文）、Seedance 转场指南、Hailuo 轨迹匹配文。**V4.3 后用户升维定调（对照 foyege 哈利波特片）：硬切问题的主战场在剧本/分镜层，不在装配层。**

## 三层归因模型（用户裁决固化）
| 层 | 职责 | 手段 | 越层补救的极限 |
|---|---|---|---|
| ①剧本/分镜层 | 切的动机与密度 | 每条切缝有动机（动作/视线/转镜/收黑/插入镜）；密度预算 | **不可补救**——无动机的跳（如喝咖啡→独立桌杯静物）后期造不出"为什么要看那里" |
| ②生成层 | 镜内带观众过空间 | 转镜头（慢横摇/缓推=安全集；跨亮灯运动=危险集，G4v2/v3 实证）；15s 多镜一体（段内切由模型自管，天然软）；同take覆盖切点 | 需在生成前设计，事后无take可用则失效 |
| ③装配层 | 降摩擦 | 色彩匹配/声桥/底噪/颗粒/正规收黑/软擦除 | 只能降摩擦，不能造动机；对①层债无效 |

## 用户三观察（foyege 对照，固化为律）
1. **切镜密度预算律**：静戏 30s ≤3-5 镜、单镜 5-10s。《未发送》V4.3 = 5镜/22.7s 均长4.5s，密度超标；且修复史每否决一次分裂一个新take，装配把碎take全缝合——**修复债变切镜债**，修复策略必须考虑take完整性。
2. **转镜头替代切律**：场景/构图变化优先用镜内运镜完成（模型安全集内），不用新切。
3. **正规收黑律**：硬切处彻底收黑再起新镜：出黑≥0.5-0.7s+入黑≥0.3-0.5s（总≈1s），清黑（收黑必须在颗粒层之下或之后，黑帧不挂颗粒），用于章末。V4.2 教训：0.24s=3+3帧读成闪跳故障；不是收黑错了，是尺寸错了。

## 解法分级（从零成本到高成本）
| 级 | 手段 | 说明 | 状态 |
|---|---|---|---|
| 0 | 声桥 J-cut | 下一段环境/动作声提前 0.3-0.8s 进入，耳朵先过缝，眼睛就不觉得硬 | ✅ V4.1 实装（acrossfade 0.45s） |
| 0 | 连续房间底噪床 | 全片铺同一低响度 room tone，任何切点声音都不落空 | ✅ V4.1 实装（尾镜底噪循环 0.10 音量） |
| 0 | 统一质感层 | 全片统一细颗粒+微调色（noise+curves 在字幕之下），遮住跨段微差 | ✅ V4.1 实装 |
| 0 | 逐段统计色彩匹配 | signalstats 量每段 YUV 均值，按锚段（G2）逐段校正亮度/色偏——V4 实测 G1 比 G2 暗 37/255 且偏冷，这是"每条缝都硬"的画面层根因 | ✅ V4.2 实装 |
| 0 | ~~黑场微顿~~ **失败已废弃** | 0.24s（3+3帧）fade-through-black 短于可读阈值，观众读成闪跳/丢帧故障而非转场；且颗粒滤镜打在黑帧上成"噪点黑"（V4.2 实证，用户抓到 20s 处闪跳）。教训：dip 类转场 <0.4s 不可用；若用需清黑且 ≥0.5s | ❌ V4.2→V4.3 废弃 |
| 0 | 软擦除过渡 smoothleft | xfade smoothleft 0.5s：方向性拖影过缝，运动模糊遮几何差，不落黑不闪；中点帧验证无撕裂/条带/闪白 | ✅ V4.3 实装 |
| 1 | 插入镜 cutaway | 突兀切缝之间垫 0.5-1s 短镜（门缝、拖鞋、蒸汽、手部细节），观众注意力换轨后再切 | 待定（需新生成或从现有 take 裁） |
| 1 | cut-hide 藏切 | 借遮挡物（门框、被子起伏、杯子前景经过）藏住切换瞬间 | 生成时设计 |
| 2 | 动作匹配切 | 切点落在动作进行中（手伸到一半切视角），大脑忙于补全动作就忽略空间跳 | 需重排切点或重生成 |
| 2 | 视线引导切 | 上一段末她看向画外，下一段接她所看物体，切点有因果 | 需镜头设计支持 |
| 3 | 轨迹匹配 | 两段主体运动方向/速度在切点对齐（Hailuo trajectory matching） | 提示词+剪辑双侧约束 |

## 与既有四律的关系
- 双重对比切律（§3.4 第二律）仍有效：对比切是"有意的跳"，本文件处理的是"无意的跳"——先排除微差与声断，剩下的跳才是创作。
- 叠化禁用不变：叠化在实拍里软、在 AI 片里暴露两段几何互搏（V3 实证）。

## 缺口状态（2026-10-31 用户定调：体系前进一大步，镜头切换生硬=唯一剩余缺口，解决方向待验证）

## 装配纪律（并入 PIPELINE_STAGE_CHECKS 环节四）
1. 多段装配默认输出声桥版+底噪版+统一质感版，无声桥版仅留对照。
2. 每条切缝标注类型：同take裁切/跨take裁幅/跨段；跨段缝必须有声桥或插入镜二者之一。
3. 切缝人工目审逐条过，不看整片"感觉还行"。

## V4 切缝逐条诊断
| 缝 | 类型 | V4.1 后状态 |
|---|---|---|
| 放杯→侧卧触床 | 跨take+跨幅，最硬 | 声桥+质感缓解；根治需插入镜（拖鞋/门缝特写）或动作匹配重排 |
| 触床→醒脸 | 同take裁切 | 本就近无缝，声桥加固 |
| 醒脸→读笺 | 跨段 | 声桥缓解；视线动机已存在（她看向柜面） |
| 读笺→静物 | 跨段 | 声桥缓解；静物前动作已收住，属合理收尾切 |
