# 821 身份混合管线知识库 V1（真实人物出演 AI 短片）

来源：concert30《被卷进高潮》v1→v3 全程实证（2026-09，v3 用户验收通过：剧情完整、光影统一、双身份全窗口过线）。
本文是 [CREATIVE_CINEMATIC_SYSTEM_V2.md](CREATIVE_CINEMATIC_SYSTEM_V2.md)（创意上限）的执行层姊妹篇（执行上限：真实人物身份如何被 AI 保住）。
所有数字为 SFace/YuNet 实测，非估计。

## 0. 核心结论（一句话）

**身份由真实照片几何承载，场景由生成承载，两者用"生成 + 逐帧换脸修复"焊接。** 纯生成公众人物不可交付（0.35–0.52），纯真实素材剧情不完整，混合修复后 0.60–0.81 全过线。

## 1. 架构决策树

| 条件 | 采用 | 证据 |
|---|---|---|
| 公众人物有大量清晰官摄/照片 | **生成场景 + ReActor 换回真人脸** | 华晨宇：纯生成 0.42–0.52 FAIL → 修复后 0.60–0.69 PASS |
| 普通人有 4+ 张日常照片 | **Ref2VA 参考图配方直接生成，漂了再修** | 女孩：配方生成 0.53–0.60，修复后 0.74–0.78 |
| 真实素材与生成同框出现的光影割裂 | **同一个人的所有镜头统一走生成域**，真实素材只做开场/收尾锚 | v2 全真实歌手被否：光影差异 + 剧情不完整 |
| 剧情需要真实素材无法拍的互动（拉上台/合影） | **双人生成底片 + 链式角色修复** | S4 拉上台 / S6 合影全过 |

## 2. Ref2VA 身份配方（女孩四轮迭代收敛，华晨宇转置验证）

工作流：RunningHub H3 Ref2VA（int8 UNET + SameFace_Fix + turbo_6step，1344x768，4–15s，≤9 参考图，~47 币/5s）

1. **Picture 1 = 确定性人脸裁切锚**：YuNet 最大脸 bbox × 1.5–1.6 外扩裁切（禁手工截，禁含他人的原图）。海报/合照原图直接喂会污染嵌入（实测 1/3 参考被拒）。
2. **SameFace_Fix = 0.5**（0.35 不足以锁日常照身份）。
3. **参考图职责显式声明**（Ref2VA 规范）：每张 Picture 声明它供脸几何/表情/发型/全身服装中的哪一个。参考包：脸裁切 + 表情 + 正面 + 全身，4 张。
4. **硬属性每帧强制**：女孩=细圆框眼镜+长直黑发；华晨宇=金发+粉亮片演出服+红色无线麦。属性写进 "Hard mandatory attributes in EVERY frame"。
5. **单一连续场景，禁蒙太奇**：蒙太奇提示会漂成群像/自拍（女孩消失，0.2652）。
6. **首尾正脸锚**：脸在第 1 秒和最后 1 秒必须朝镜头，中间可动作。
7. **动作指令按段定制**（action_mandate 字段）：冲刺段/追光站立段/穿人群段各写各的，不共用一句"全程奔跑"。
8. **禁区清单**：自拍、集体照、朝镜头的手机、第二突出女性/男性、已解析的观众脸、空旷通道、第二 prominent 人。

**已知上限**：Ref2VA 用身份换动作——全力冲刺不可得，"energetic fast-walk"是天花板，冲刺能量靠剪辑提速（1.6x 实测有效）。

## 3. ReActor 角色感知链式修复（本项目最大方法创新）

工作流：RunningHub 2005804455352303618（node 10=源脸 LoadImage，node 11=目标视频 VHS_LoadVideo，node 15=input_faces_index 选脸）。**输出是 RIFE 半速**（10.25s@12fps），剪辑前 setpts=PTS/2 + fps=24 回速。

1. **先做角色映射再动手**：YuNet 逐帧检测 top-2 脸 × SFace 对双角色参考打分，输出"时间→脸索引→角色"表。
2. **次序稳定 → 固定索引链修**：S5 双人段她恒 0 号他恒 1 号（11/11 采样），先修 1 号（他，H 裁切）再在输出上修 0 号（她）。实测双人同框 0.71–0.76 / 0.56–0.69。
3. **次序漂移 → 按剧情弧线切窗分段修**：S4 拉拽段他 0 号 / 过渡段她 1 号 / 上台段她 0 号；三窗各自定向修，同源素材 concat 拼回无痕（修复不动时间轴）。
4. **单人段直接 0 号修**。
5. **修复源脸必须用真实照片裁切**（不是生成参考），这样交付身份的几何来源是真实素材。

## 4. 身份门禁体系（qa_identity.py）

- 检测：YuNet conf ≥0.85 且高 ≥48px 且 Laplacian ≥60 = "清晰脸"；每帧取 top-2 最大清晰脸，角色分 = max。
- 判定：SFace 余弦，同人阈值 0.363（820 实测标定）；交付线：角色窗口清晰脸 median ≥0.60，英雄帧 ≥0.70，地板 ≥0.50，跨角色边距 ≥0.12。
- **按角色窗口分读，禁整片聚合**：混合角色整片 both 模式的 median 无意义（互相稀释必然 FAIL）。
- **暗场折扣**：追光+黑人群场景嵌入余弦系统性低 0.10–0.15（亮环境修复 0.66–0.77 → 暗场 0.49–0.62）。视觉+真实源+多窗口锚共同定论，不死磕单窗数字。

## 5. 已知失败模式表

| 症状 | 根因 | 解法 |
|---|---|---|
| 蒙太奇提示后主角消失（0.27） | Ref2VA 把"多场景"读成群像 | 单一连续场景 |
| 属性对但人不对（0.17） | 参考图无脸裁切锚 | P1 裁切锚 + SameFace 0.5 |
| 追光段身份渐进漂移（0.59→0.18） | 强光+大表情事件 | 生成后修复，别指望生成自己扛住 |
| 联系表说"无接触/崩坏"但全分辨率正常 | 480px 缩略图系统性低报 | 关键剧情点必须全分辨率抽帧 |
| 视觉模型判决自相矛盾 | 提问泄漏了量化分数，模型自造阈值锚定 | 提问只描述任务，不给数字 |
| 生成帧带官摄水印/字幕 | Ref2VA 继承参考图水印 | 用过官摄参考的底片在剪辑里安全裁切（crop 顶部 40px+底部字幕区） |
| 修复输出时长翻倍 | RIFE multiplier=2 且 12fps 封装 | setpts=PTS/2 回速 |
| 单帧剧烈大表情处换脸几何残留 | inswapper_128 分辨率上限 | 接受（音乐节奏下不可见），或换更高分辨率 swap 模型 |

## 6. 流程顺序（可复用生产链）

```
参考包构建（人脸裁切锚+QA） → 段表（generation_mode + plate + action_mandate + anchors）
→ 预检（refs 存在/时长/节点图） → Ref2VA 生成底片 → 联系表初筛 → 角色映射
→ ReActor 修复（单人0号 / 双人链修 / 漂移切窗） → 回速 → 段级门禁
→ 剪辑组装（节拍锚 + 变速 + 安全裁切 + 统一调色 + 真实母轨）
→ 母版窗口密采样双角色门禁 → 全分辨率关键帧人工核验 → 预览交付
```

## 7. 成本台账（RunningHub 币）

- Ref2VA 5s 底片 ≈ 47 币（8–10 分钟）
- ReActor 修复 5s ≈ 10–15 币
- 全程一个 30s 双人短片：v2+ v3 合计 ≈ 800 币（含 4 次 S3 迭代教训成本；熟练后预计 350–450 币）

## 8. 边界

- 本管线保"同一真人身份"，不保"演出真实细节"——公众人物的表演质感仍需真实素材锚定。
- SFace 对舞台强光/大角度不鲁棒，暗场/仰角分值折扣是度量问题不是身份问题（已实测压光不能恢复分值）。
- 双人同框链修依赖检测次序稳定或可切窗；三人以上同框未验证。
- 女孩服装跨段不一致（各段生成各自发明演出服）是遗留问题，如需连续性应在 plate 里锁定服装描述。
