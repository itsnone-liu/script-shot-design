# 广告故事方法：先让观众关心结果，再让产品介入

上一版咖啡实验的问题不是产品镜头少，而是把产品动作误当成叙事。短片必须先建立人物想完成的事情，再让产品在因果链中发挥作用。

## 30 秒故事骨架

```text
人物目标 → 阻碍/失败 → 明确转折 → 行动改变 → 可见结果 → 品牌承诺
```

其中：

- 目标必须能用一个动作或结果验证；
- 阻碍必须发生在画面中，不能只写“感觉疲惫”；
- 转折必须由产品体验、产品特征或与产品相关的观察触发；
- 结果必须是转折后的行动造成的，不允许“喝完就突然成功”；
- 产品动作（开盖/饮用）最多出现两次，且每次都有不同叙事功能；
- 其余镜头表现目标、阻碍、行动和结果，而不是重复展示杯子。

## 故事闸门新增检查

1. 能否一句话说清人物要完成什么？
2. 是否出现至少一个可见阻碍？
3. 产品是否改变了人物的行动，而不只是出现在画面里？
4. 产品饮用动作是否超过两次？超过则退回重写；
5. 去掉产品后，故事是否仍有目标和结果？如果完全没有，说明原故事只是产品演示；
6. 结尾是否呈现结果和品牌承诺，而不是再次喝咖啡？
