## 1. 文章一：气泡水创意广告全流程

文章展示的是一个具体的产品广告制作教程，主链路是：

```text
产品图/产品描述
→ 文生图生成产品和中间画面
→ 大模型根据产品图生成约 6 镜头、30 秒、无台词创意脚本
→ 大模型补写画面提示词
→ 文生图生成关键帧
→ 图生视频/首尾帧生成动态镜头
→ 配音、剪辑、品牌收束
```

有价值的部分：

- 明确采用“产品/水果/果肉/气泡水”的视觉转化主线；
- 先让大模型产出多组大体创意，再挑选片段，不把第一版直接当终稿；
- 脚本需要同时给镜头时长、动态提示词和声音/剪辑方向；
- 产品展示图、关键帧、动态镜头、配音剪辑分工不同；
- 说明了图像提示词和视频动态提示词不能混为一谈。

局限：

- 这是教程式线性流程，核心脚本 Prompt 仍然比较宽泛；
- 没有明确的故事声明、人物目标、阻碍、选择和状态变化；
- 视觉段落很强，但更接近产品视觉秀，不足以直接作为 821 的剧本系统；
- 没有结构化的反方审稿、可拍性诊断或失败回写。

对 821 的吸收：保留“产品图/参考图 → LLM 多方案脚本 → 关键帧 → I2V → 声音剪辑”的工具链，但必须加在 Story Gate 之后，不能让视觉炫技替代故事。

## 2. 文章二：素材定位—创意拆解—脚本重构

文章的核心不是单次生成，而是一个更值得 821 借鉴的广告创意工作流：

```text
数据化定位高表现广告素材
→ 多模态模型整体评估
→ 按时间轴结构化拆解脚本
→ 提取场景、字幕、卖点、情绪、节奏、视觉策略和转化逻辑
→ 输入新产品、目标受众、卖点和语言风格
→ 重构为定向的新广告脚本
```

关键经验：

- 不凭主观感觉找参考，先按曝光、生命周期、互动、受众等条件筛素材；
- 先整体评价“值不值得拆”，再进入细节拆解；
- 剧本拆解必须按时间轴，而不是只输出一段总结；
- 拆解内容包含场景、字幕、核心卖点、情绪价值、节奏、视觉策略和转化逻辑；
- 重构时必须显式输入产品、受众、核心卖点和语言风格；
- 不是复制原广告，而是把可复用结构迁移到新产品和新受众。

对 821 最重要的启发：剧本系统的输入不应只有用户一句创意，还应有“参考素材拆解卡”和“重构约束”。

## 4. “让大模型来完成”应采用的方式

同意让大模型完成剧本，但不是一次性让它“写一个广告脚本”。更稳的链路是：

```text
用户创意/产品资料
→ LLM 生成 3–5 个差异化概念
→ 选择或确认参考广告拆解卡
→ LLM 先写故事声明
→ LLM 写状态转换 beat
→ LLM 写场景卡
→ LLM 写可拍剧本
→ StoryEditor/AudienceAdvocate/BrandStrategist/ProductionEditor/AdversarialReviewer 审稿
→ LLM 按诊断结果重写
→ 用户确认剧本
→ 才进入分镜和视频生产
```

LLM 应负责：

- 从产品和受众资料生成概念；
- 从参考素材抽取时间轴、结构和卖点；
- 把参考结构迁移到新产品，而不是复制表面画面；
- 写场景卡、动作、声音、必要对白和旁白；
- 根据审稿问题进行定向重写。

确定性代码应负责：

- 时长和镜头预算；
- beat 是否存在 `state_in → visible_event → choice → state_out`；
- 前 20% 是否建立目标；
- 中段是否有可见阻碍；
- 产品动作次数；
- 每镜头是否有叙事功能；
- 是否存在突然成功、无功能对白和无关支线；
- JSON Schema、版本和审批状态。

## 5. 对当前咖啡广告的直接结论

《最后一页》已经比“连续喝咖啡”明显更好，因为它有：

```text
截止压力
→ 修改失败
→ 离开屏幕观察
→ 光影触发新视角
→ 主动重组页面
→ 提交成功
→ 产品/品牌收束
```

下一轮不应先继续生成视频，而应让大模型基于：

1. 当前 `story_statement.json`；
2. 当前 `beat_sheet.json`；
3. 当前 `scene_cards.json`；
4. 这两篇文章抽取出的参考广告工作流；
5. 821 自己已有的 Story Gate；

进行一次“编剧室重写”，重点检查：

- 参考广告的结构是否真正迁移，而非只模仿镜头外观；
- 产品如何改变人物选择是否足够清楚；
- 前 5 秒是否让观众知道人物正在解决什么问题；
- 光影观察如何在无对白下被观众理解；
- 结尾品牌归因是否自然且可拍。

## 结论

两篇文章共同支持一个判断：

> 821 需要大模型参与剧本，但大模型应当是“分阶段编剧和重写者”，不是一个只接收一句创意、直接吐出最终脚本的黑盒。

文章一提供产品视觉广告的生产链路；文章二提供更重要的“参考素材结构化拆解 → 面向新受众和产品重构”的编剧方法。821 应把二者合并到现有的故事闸门和结构化中间产物中。
